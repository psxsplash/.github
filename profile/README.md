**psxsplash makes PlayStation 1 games.** One download holds the editor, the engine and the pcsx-redux emulator: build a scene, script it in Lua or with blocks, press Play, and run the same game on a real console or burn it to a disc.

[Website](https://psxsplash.github.io) · [Documentation](https://psxsplash.github.io/docs/) · [Download (nightly)](https://github.com/psxsplash/splashedit-ng/releases/tag/nightly)

| Repository | What it is |
|---|---|
| [splashedit-ng](https://github.com/psxsplash/splashedit-ng) | The psxsplash editor: scenes, import, Lua and block scripting, UI, cutscenes, Play |
| [psxsplash](https://github.com/psxsplash/psxsplash) | The psxsplash engine that runs your game on the PS1 |
| [docs](https://github.com/psxsplash/docs) | The documentation site |
| [psxsplash.github.io](https://github.com/psxsplash/psxsplash.github.io) | The website |
| [splashedit](https://github.com/psxsplash/splashedit) | The legacy Unity-based editor, frozen at 2.4.0 ([docs](https://psxsplash.github.io/docs/unity/)) |
